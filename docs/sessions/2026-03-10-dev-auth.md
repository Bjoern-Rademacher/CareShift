# Session: Dev authentication scaffold

## Intent

Introduce a server-readable dev authentication source and expose CurrentUser via an API session endpoint.

## What works

- Dev login sets HTTP-only cookie `sp_dev_session`
- Logout clears session cookie
- `/api/auth/session` returns CurrentUser when authenticated
- `/api/auth/session` returns 401 when unauthenticated
- Role switching works (admin / employee / viewer)
- Dev navigation added for quick route access

## Compromises

- Authentication is dev-only (cookie with serialized user)
- No permission enforcement yet
- No persistent user store

## Out of scope

- Real authentication provider
- Role enforcement in API endpoints
- UI role indicator
- Production auth security

## Next intent

Add role enforcement in API endpoints and hide admin-only controls in the UI.
